STRUKTUR ALUR KERJA PENGAMBILAN DATA & IMPLEMENTASI

Fase 1: Perencanaan Lapangan

  • Pemilihan wilayah dialek target
  • Penyusunan Daftar Swadesh (200 kosa kata)
  • Perizinan & Informed Consent Penutur Asli

Implementasi Preview:

Tim Peneliti mendatangi titik lokasi masyarakat adat untuk memetakan variasi fonetik menggunakan instrumen kuesioner digital.

Fase 2: Pengambilan Audio

  • Elicitation & Wawancara Terstruktur
  • Rekaman Audio WAV 24-bit/48kHz
  • Penyematan Metadata GPS & Waktu

Implementasi Preview:

Audio direkam menggunakan perangkat keras peredam bising portabel guna menghasilkan sampel suara fonem yang bersih.

Fase 3: Validasi Linguistik

  • Audio Denoising & Normalisasi Frekuensi
  • Transkripsi International Phonetic Alphabet (IPA)
  • Quality Control oleh Ahli Bahasa Daerah

Implementasi Preview:

Penyuntingan gelombang suara dan pencocokan simbol fonetik agar valid sebelum dimasukkan ke dalam sistem basis data.

Fase 4: Integrasi Sistem

  • Strukturisasi Format JSON / CSV
  • Injeksi ke DB Storage Terpusat
  • Indexing API untuk Web & Mobile Apps

Implementasi Preview:

Data siap diakses secara publik melalui antarmuka web interaktif dan aplikasi mobile lintas platform.
